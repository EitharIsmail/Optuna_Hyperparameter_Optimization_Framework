# Optuna: Hyperparameter Optimization Framework

## Overview

This repository contains a presentation and practical learning materials introducing **Optuna**, an open-source framework for automated hyperparameter optimization in Machine Learning and Deep Learning.

The presentation explains why hyperparameter tuning is important, how different optimization strategies work, and how Optuna makes the experimentation process more efficient through intelligent sampling, pruning, visualization, and integrations.

## Part of SAiR – Applied Deep Learning with PyTorch

*This presentation complements the SAiR Applied Deep Learning with PyTorch course by introducing automated experimentation and hyperparameter optimization as practical skills for developing and improving deep learning models.*


## Topics Covered

1. **Hyperparameter Optimization Fundamentals** – Parameters vs. hyperparameters, and why tuning matters.
2. **Optimization Strategies** – Manual Search, Grid Search, Random Search, and Bayesian Optimization.
3. **Optuna Fundamentals** – Studies, Trials, Objective Functions, and Search Spaces.
4. **Samplers** – Random Sampling, TPE, CMA-ES, and other optimization strategies.
5. **Pruning** – Stopping unpromising trials before completing all training epochs.
6. **Optuna Ecosystem** – Optuna Dashboard.
7. **Practical Applications** – Applying Optuna to Machine Learning and PyTorch Deep Learning models.

## Learning Objectives

By the end of this presentation, you should be able to:

- Understand the role of hyperparameter optimization in Machine Learning and Deep Learning.
- Explain how Optuna explores and evaluates different hyperparameter configurations.
- Implement Optuna within existing PyTorch training workflows.
- Use samplers and pruners to improve optimization efficiency.
- Analyze optimization results and identify promising hyperparameter configurations.
